# 社群投稿：Google 表單設定與審核流程

對應 DECISIONS D-024。投稿者在 App 的「🤝 分享經驗」頁填寫並通過檢查後，App 會開啟這份 Google 表單並帶入投稿內容（JSON）。表單只負責**收件**，題目設計刻意很少，所有的結構化欄位與檢查都在 App 裡完成。

---

## 1. 建立表單（RPAI 帳號，約 10 分鐘）

到 https://forms.google.com 建立新表單：

**表單標題**：個人成長導航系統｜職業經驗投稿
**說明**：
> 請先在「個人成長導航系統」App 的「🤝 分享經驗」頁填寫，App 會把內容帶到下方欄位。只分享你親身做過或直接觀察到的經驗。投稿由 RPAI 數位優化器審核，通過後才會公開。

| # | 題目 | 類型 | 必填 | 說明 |
|---|---|---|---|---|
| 1 | 投稿內容（由 App 帶入，請勿修改） | 段落 | ✅ | App 會自動帶入或請投稿者貼上 JSON |
| 2 | 我確認以上內容是我的親身經驗或直接觀察，不是推測，也沒有洩漏營業秘密 | 核取方塊（單一選項：「我確認」） | ✅ | App 內已勾過一次，這裡再確認一次 |
| 3 | 我同意投稿內容以 CC BY-NC-SA 4.0 公開，並授予 RPAI 數位優化器與 Eddy Wu 吳宗賢非專屬、永久、全球、可再授權的使用權（包含商業用途） | 核取方塊（單一選項：「我同意」） | ✅ | 授權同意的書面紀錄 |

**設定**（⚙ 設定）：
- 回覆 → **不要**勾「限制只能回應 1 次」（避免強制登入 Google，允許匿名投稿）
- 回覆 → 「收集電子郵件地址」：**不收集**（email 已是 App 內的選填欄位）
- 回覆分頁 → 「連結至試算表」→ 建立新試算表

## 2. 把表單接回 App

1. 表單右上 ⋮ →「**取得預先填入的連結**」
2. 在第 1 題隨便打 `x`，按「取得連結」→「複製連結」
3. 連結長這樣：`https://docs.google.com/forms/d/e/XXXX/viewform?usp=pp_url&entry.123456789=x`
4. 把兩個值告訴 Claude（或自己填進 `data/site.json`）：
   - `contrib.formUrl` = `https://docs.google.com/forms/d/e/XXXX/viewform`（`?` 之前）
   - `contrib.entryId` = `123456789`（`entry.` 後面的數字）
5. `python tools/build.py` → commit → push，GitHub Pages 會自動更新。

App 的行為：投稿內容不太長（精簡 JSON 編碼後 < 6000 字元，約 3–6 項能力）時直接預填到第 1 題；太長時改為複製到剪貼簿、開啟表單，請投稿者貼上；瀏覽器不允許複製時改為下載 JSON。`formUrl` 留空時，App 只會下載投稿檔。

## 3. 審核（在連結的試算表）

在試算表右側新增 3 欄：**審核狀態**（下拉：待審／通過／需補充／退回）、**審核備註**、**匯入日期**。

審核標準（「只能分享自己的經驗」靠這些判斷）：
- [ ] **例子是具體事件**：有情境、行動、結果（最好有數字），而不是「要很會溝通」這類通則
- [ ] **例子與宣稱的等級相符**：寫「需要 5 級」的能力，例子要看得出定義標準、對外代表的程度
- [ ] **年資與職稱合理**：年資 1 年卻描述主管視角的內容，標「需補充」
- [ ] **沒有營業秘密或個資**：客戶名稱、內部數字、可識別的同事等，請刪除或退回
- [ ] **不是複製網路上的職能說明**：可疑時以例句搜尋比對
- [ ] 兩項同意都有勾

「需補充」時，若投稿者留了 email，可回信請對方補例子；沒有 email 就標退回。

## 4. 通過後怎麼進到網站

把通過的那幾列（第 1 欄的 JSON）交給 Claude，請它：
- 同一職業累積到一定份數（建議 ≥ 3 份）再整理成框架包放進 `data/packs/`，或併入既有框架的等級描述與角色目標；
- 在 `meta.sources` / `contributor` 註記「社群投稿（N 份）」，署名者列入 `contributors`（匿名者不列名）；
- `python tools/build.py`、commit、push。

> 之後可以做 `tools/import_contributions.py`，把試算表匯出的 CSV 自動整理成草稿（BACKLOG #11）。
