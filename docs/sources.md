# 資料來源與授權

本頁記錄這個專案「可以用」與「不能用」的外部職能/職業資料，以及引用時要怎麼標示。
查核日：2026-10-23。新增任何外部資料前，請先在這裡登記，並在 `data/*.json` 的 `source` 欄寫明出處。

## 目前狀態（誠實標示）

| 框架 | 成熟度（`maturity`） | 說明 |
| --- | --- | --- |
| tech / biz / ops / pro / creative | 草擬版 | RPAI 依實務經驗撰寫，**尚未逐項對照官方職能基準**。App 的「② 目標」頁會顯示這個標示與可對照的公開資料連結。 |
| automation | 實務版 | 擁有者 Eddy 的自動化 / AI 顧問實務框架。 |
| 使用者匯入的框架包 | 依匯入檔 `meta.source` | 由分享者自負來源責任，經審核後才會併入。 |

`maturity` 只能是 `草擬版`、`實務版`、`已對照官方` 三者之一（`tools/build.py` 會檢查）。
只有逐項比對過官方基準、並在 `source` 寫明基準代碼與版本後，才能標成「已對照官方」。

> 以前 `frameworks.json` 寫「分級精神參考 SFIA 8 與 O*NET」，但其實沒有逐項對照，而且 SFIA 需要付費授權，已於 2026-10-23 更正。

## 引用格式

政府資料（依政府資料開放授權條款附件格式；**沒有正確顯名，授權視為自始不存在**）：

> 資料來源：勞動部勞動力發展署 iCAP 職能發展應用平台，「會計主管職能基準 FAC1211-001v1」（110 年），依政府資料開放授權條款第 1 版（https://data.gov.tw/license）。本 App 已摘要改寫。

O*NET：

> 本內容包含 O*NET 31.0 Database 之資訊，由 USDOL/ETA 依 CC BY 4.0（https://creativecommons.org/licenses/by/4.0/）提供，個人成長導航系統已翻譯並修改；USDOL/ETA 未審核或背書這些修改。O*NET® 為 USDOL/ETA 之商標。

ESCO（如果使用）：

> This service uses the ESCO classification of the European Commission.（已修改）

## 必須遵守的限制

- **授權相容**：政府開放授權、CC BY 4.0、ESCO 都允許任何用途，可以放進本專案；但本專案的 CC BY-NC-SA 4.0 只適用於我們自己寫或改寫的部分，**第三方資料仍依原授權**。
- **不得扭曲原意、不得暗示機關背書**。AI 改寫過的內容標「依 XX 改寫」，不要寫成「XX 官方職能」。App 已在框架依據加註「不代表任何機關的官方標準」。
- 政府資料不保證正確；個資不適用開放宣告。

## 範例：財務主管可以怎麼對照

（供日後把 `pro` 框架從「草擬版」升到「已對照官方」時參考）

- iCAP「會計主管」FAC1211-001v1（職業 1211 財務經理人員，基準級別 4）：統籌會計部門作業與稅務、督導覆核財務作業與報表、協助財務投資規劃（預算、成本分析、投資規劃，級別 5）。基準註明建議併用「企業財務人員」。
- iCAP「企業財務人員」FFN2412-003v2：外部金融資訊分析、企業價值評估、預算管理報表與差異分析、資金收付、稅務與移轉訂價。
- O*NET 11-3031.00 Financial Managers：Job Zone 4，含 Skills / Knowledge 的 Level 分數，可換算成本 App 的 1–5 級。
- 證照對照：會計師 → 會計主管（出自 114 年「證照 × iCAP 職能基準關聯性一覽表」，原始發布機關與授權未確認，只列事實不複製表格）。
